Quick start

Documentation

v0.1.0 release in preparation Colab Cola runs on Python 3.12 or later. The commands below are intended for the first public release, which is not yet confirmed available on PyPI.

Install

$ python -m pip install colabcola

Connect your Google account

$ colabcola login

Follow the interactive prompts to authorize Google Colab and per-file Google Drive access and select or create an execution project. Colab Cola ships with a desktop OAuth client, so you do not need to create your own OAuth application for the default flow. You may use colabcola login --help to see advanced account and project options.

Package a Python workload

$ colabcola package --save-colaml train.colaml -- python train.py

Run the command from your project directory, ensuring train.py exists. The resulting recipe records how to package the workload.

Execute and recover results

$ colabcola run --colaml train.colaml --run-dir runs/train

The run directory stores the local journal used to follow or reconnect to a managed execution. The CLI can publish logs, checkpoints, and recovered artifacts through your configured Google Drive folder. Runtime allocations and Drive transfers depend on your Google account and Google Colab availability.

Requirements and access

  • Python 3.12 or newer.
  • A Google account that can access Google Colab.
  • Google Cloud project configuration as requested by onboarding, with the required API enabled.
  • Authorization for the specific Google Drive files used by Colab Cola.

For help with an installed version, run colabcola --help, colabcola package --help, or colabcola run --help.
